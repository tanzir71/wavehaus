Wavehaus’s first browser preview includes the landing and documentation, an installable PWA, twelve original generated tracks, browser-local uploads and a background-play guide with a 30-second test.

Preview: https://tanzir71.github.io/wavehaus/
App: https://tanzir71.github.io/wavehaus/app/

What to try:
1. Play a generated track, seek on its waveform and open Now Playing.
2. Upload your own audio; reload and find it in Your library. Everything stays in this browser.
3. In Brave on Android, install the PWA, enable Background play and run the screen-off test.

M0 is a demo preview. Production PHP and Worker packages begin with M1. Physical Android/iPhone background-play acceptance has not yet been performed; later features are listed in handover/TASKS.md.
